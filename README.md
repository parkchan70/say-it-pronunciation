# Say It! 발음 채점기

중학교 영어 수업용 말하기 연습 앱입니다. 문장을 듣고 따라 말하면, 음성 인식이 알아들은 단어는 초록색, 놓친 단어는 빨간색으로 표시하고 0~100점으로 채점합니다.

## 바로 쓰기
GitHub Pages 주소로 접속하면 설치 없이 사용할 수 있습니다. 컴퓨터·안드로이드는 **Chrome**, iPhone·iPad는 **Safari**에서 말하기 채점이 됩니다. 다른 브라우저(카카오톡 안, 엣지, 웨일 등)로 열면 화면 맨 위에 Chrome·Safari로 여는 버튼과 안내가 나옵니다. 처음 '말하기'를 누를 때 마이크 사용을 허용해 주세요.

## 기능
- 중1·중2·중3 수준 예문 각 10개 (한국어 뜻 포함)
- 듣기 / 천천히 듣기 (원어민 발음)
- 말하기 → 잠시 멈추면 자동 채점, 단어별 색 표시
- 틀린 단어를 누르면 그 단어 발음 듣기
- 오늘의 기록 (도전 횟수, 평균 점수)
- 선생님 문장 넣기: `영어 문장 | 한국어 뜻` 형식으로 한 줄씩 (브라우저에만 저장)

## 참고
- 음성 인식은 문맥으로 단어를 추측하기 때문에 실제 발음보다 점수가 조금 후하게 나올 수 있습니다. 정밀한 발음 평가보다는 말하기 연습용으로 사용해 주세요.
- 학생의 음성은 저장되지 않습니다. 음성 인식은 브라우저(Chrome·Safari)의 음성 인식 서비스를 사용합니다. 음성 인식이 안 되는 환경에서도 키보드 음성 입력으로 채점할 수 있습니다.
- HTML 파일 하나로 되어 있어 `index.html`을 내려받아 고쳐 쓸 수 있습니다.
